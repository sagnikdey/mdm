# Radius

Corners grow with the surface. Pick by role: `control` for buttons and fields, `container` for cards, `overlay` for menus and dialogs, `pill` for badges and chips.

## Scale

export const scale = [["xs", "4px"], ["sm", "6px"], ["md", "10px"], ["lg", "14px"], ["xl", "20px"], ["2xl", "28px"], ["pill", "9999px"]];

<div className="sb-unstyled flex flex-wrap gap-6 text-foreground">
  {scale.map(([name, value]) => (
    <div key={name} className="grid justify-items-center gap-1">
      <div className="size-16 border-2 border-primary bg-secondary" style={{ borderRadius: `var(--radius-${name})` }} />
      <code className="type-caption">--radius-{name}</code>
      <span className="type-caption text-muted-foreground">{value}</span>
    </div>
  ))}
</div>

## Roles

export const roleList = [["control", "md · 10px", "Buttons, inputs, selects"], ["container", "lg · 14px", "Cards, alerts, groups"], ["overlay", "xl · 20px", "Menus, popovers, dialogs"], ["pill", "9999px", "Badges, chips, avatars"]];

<div className="sb-unstyled grid grid-cols-4 gap-4 text-foreground">
  {roleList.map(([role, step, use]) => (
    <div key={role} className="grid gap-2">
      <div className="h-16 border border-border bg-surface shadow-resting" style={{ borderRadius: `var(--radius-${role})` }} />
      <code className="type-code">rounded-{role}</code>

    </div>
  ))}
</div>

## Concentric corners

Inner radius = outer radius − padding.
