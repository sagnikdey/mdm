# Typography

Inter for the interface, JetBrains Mono for code. Use the `type-*` roles for headings and copy; they set size, line height, weight and tracking together.

## Roles

export const roles = [
  ["type-display", "40–60 fluid / 1.05 · 600", "Ship calmer interfaces"],
  ["type-h1", "32–40 fluid / 1.1 · 600", "Workspace settings"],
  ["type-h2", "24 / 1.25 · 600", "Billing and invoices"],
  ["type-h3", "18 / 1.4 · 600", "Payment method"],
  ["type-title", "16 / 1.4 · 500", "Atlas redesign"],
  ["type-body-lg", "18 / 1.6 · 400", "A lead paragraph that introduces the page."],
  ["type-body", "16 / 1.6 · 400", "Body copy for reading: descriptions, articles, help."],
